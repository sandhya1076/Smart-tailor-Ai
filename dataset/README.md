# Dataset Information

## 1. COCO Keypoints

Purpose:
Human pose estimation and image preprocessing.

Source:
COCO Keypoints Dataset

Key information:
- Human pose images
- 17 body keypoints
- Used as secondary/public data
- Used for developing and testing the pose pipeline

The dataset will not be redistributed in this repository.
Only dataset information, preprocessing code and download instructions will be maintained.

## 2. Anthropometric Dataset

Purpose:
Training and evaluating the clothing-size prediction model.

Required features may include:
- Height
- Shoulder width
- Chest/Bust
- Waist
- Hip
- Arm length
- Leg/Inseam length
- Clothing size

The exact dataset will be selected after checking its columns, license and suitability.
